# tennis-shop - Next.js E-Commerce Frontend

A high-performance, modern online store for tennis rackets and equipment, built with Next.js for superior SEO and user experience

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
